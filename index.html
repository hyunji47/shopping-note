블로그·카페 글의 제목과 본문 요약에서 엔화 가격을 추출한 값이라 정확하지 않을 수 있어요. 카드를 눌러 원문에서 꼭 확인하세요. 카페 글은 날짜 정보가 제공되지 않습니다.

⚙️ 네이버 검색 API 설정

브라우저에서 네이버 API를 직접 호출하면 CORS로 막혀, 중계 주소(프록시)가 필요합니다. 설정이 없으면 위 '바로가기'로 검색하세요. 키는 이 기기에만 저장됩니다.

⚠️ 설정 코드에는 Client Secret이 그대로 들어 있어요. 믿을 수 있는 사람이나 내 기기로만 보내세요. "공유"는 코드를 누르면 설정이 자동 적용되는 링크로 보냅니다.

브라우저에서 네이버 API를 직접 호출하면 CORS로 막혀 중계 주소(프록시)가 필요합니다. 아래 코드를 Cloudflare Workers 등에 올리고 그 주소를 입력하세요. 국내 쇼핑·블로그·카페 검색이 모두 이 주소 하나로 동작합니다.

export default {
 async fetch(req){
  const h={"Access-Control-Allow-Origin":"*","Access-Control-Allow-Headers":"*"};
  if(req.method==="OPTIONS")return new Response(null,{headers:h});
  const u=new URL(req.url);
  const r=await fetch("https://openapi.naver.com/v1/search"+u.pathname+u.search,{headers:{
   "X-Naver-Client-Id":req.headers.get("X-Naver-Client-Id"),
   "X-Naver-Client-Secret":req.headers.get("X-Naver-Client-Secret")}});
  return new Response(r.body,{headers:{...h,"Content-Type":"application/json"}});
 }}
