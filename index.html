⚙️ NAVER API HUB 설정

네이버 검색 API는 개발자센터에서 NAVER API HUB(네이버클라우드플랫폼)로 옮겨졌어요. NCP 콘솔의 NAVER API HUB에서 Application을 등록하고 블로그·카페글 검색을 선택한 뒤, 그 Application의 인증 정보에서 Client ID/Secret을 새로 확인하세요. 개발자센터 키는 쓸 수 없어요. 키는 이 기기에만 저장됩니다.

⚠️ 설정 코드에는 Client Secret이 그대로 들어 있어요. 믿을 수 있는 사람이나 내 기기로만 보내세요. "공유"는 코드를 누르면 설정이 자동 적용되는 링크로 보냅니다.

브라우저에서 API HUB를 직접 호출하면 CORS 때문에 막힐 수 있어, 중계 주소(프록시)를 둡니다. 아래 코드를 Cloudflare Workers에 붙여넣고 그 주소를 입력하세요.

export default {
 async fetch(req){
  const h={"Access-Control-Allow-Origin":"*","Access-Control-Allow-Headers":"*"};
  if(req.method==="OPTIONS")return new Response(null,{headers:h});
  const u=new URL(req.url);
  const r=await fetch("https://naverapihub.apigw.ntruss.com"+u.pathname+u.search,{headers:{
   "X-NCP-APIGW-API-KEY-ID":req.headers.get("X-NCP-APIGW-API-KEY-ID"),
   "X-NCP-APIGW-API-KEY":req.headers.get("X-NCP-APIGW-API-KEY")}});
  return new Response(r.body,{status:r.status,headers:{...h,"Content-Type":"application/json"}});
 }}
